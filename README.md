# rocket-clash-2d
2D car-football videogame made using PyGame as an assignments for the (Interactive, Immersive Entertainment Environments) CIIE assignment at FIC, Universidade da Coruña
## A note about genAI

The owner of this repository does not endorse the use of generative AI for artistic purposes. The mere fact that it was used was a reluctant compromise due to the structure of the assignment and their timeframes and not in any way an example on how things should be done. As soon as the academic year is finished, this repository will go private or be transferred to another peer.
